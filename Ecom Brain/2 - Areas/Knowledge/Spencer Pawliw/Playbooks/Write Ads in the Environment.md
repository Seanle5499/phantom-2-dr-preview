# Write Ads in the Environment

## Summary
> Do not write static ad copy in a doc first. Write it on the actual mobile canvas so copy, hierarchy, and image work together.

## Source Evidence
- Source video: *How To Turn Research Into Winning Meta Ads (just copy me)*
- Timestamp: not available
- Quote: "when you write headlines like this in a Google doc you are not writing in the environment... write in a 9 by6 so we could see exactly how the ad is going to look because big shout out to Harry Dry your copy is like food okay how it looks matters"
- Extraction: [[2026-07-09 - NotebookLM - Creative Strategy Extraction]]

## Workflow
1. Pick angle.
2. Place product visual first.
3. Write headline directly on canvas.
4. Check legibility on mobile.
5. Cut words until the image and headline are instantly understood.

## SouthEDC Application
Design the headline around the actual carry image: pocket, hand, belt, truck, drawer, or workbench.

## Wellness Nest Application
Design the headline around the actual ritual image: scoop, pour, bedside, morning counter, or ingredient close-up.
